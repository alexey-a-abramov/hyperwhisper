# Provider API Key Setup

Use this reference to obtain API keys for each transcription provider.

## OpenAI Whisper
1. Go to https://platform.openai.com/api-keys
2. Create a new secret key.
3. Paste it into `API Key` in HyperWhisper.

## Deepgram
1. Go to https://console.deepgram.com/project
2. Open `API Keys`.
3. Create key and paste into HyperWhisper.

## AssemblyAI
1. Go to https://www.assemblyai.com/dashboard
2. Open `API Keys`.
3. Copy key to HyperWhisper.

## Google Cloud Speech
1. Go to https://console.cloud.google.com/
2. Enable Speech-to-Text API.
3. Create credentials and use key/token in HyperWhisper.

## AWS Transcribe
1. Go to https://console.aws.amazon.com/
2. Create IAM access credentials with Transcribe permissions.
3. Use your gateway/proxy auth token in HyperWhisper.

## Azure Speech
1. Go to https://portal.azure.com/
2. Create Speech resource.
3. Use key from `Keys and Endpoint`, and set endpoint in HyperWhisper.

## Rev.ai
1. Go to https://www.rev.ai/auth/signup
2. Generate access token.
3. Paste token into HyperWhisper.

## Groq Whisper
1. Go to https://console.groq.com/keys
2. Create API key.
3. Paste into HyperWhisper.

## OpenRouter
1. Go to https://openrouter.ai/keys
2. Create API key.
3. Paste into HyperWhisper.

## Google Gemini
1. Go to https://aistudio.google.com/app/apikey
2. Create API key.
3. Paste into HyperWhisper.

## Hugging Face
1. Go to https://huggingface.co/settings/tokens
2. Create access token.
3. Paste into HyperWhisper.

## Self-hosted Whisper
1. Deploy your own OpenAI-compatible Whisper endpoint.
2. Set `Base URL` to your server.
3. If enabled, set your server token in `API Key`.
